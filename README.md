# ComprehensivePerformanceSimplifier
综测！算起来真麻烦……

## 使用方法

0. 确保 3.13 >= Python >= 3.8

1. 安装 requirements.txt 中的所有依赖，不建议安装最新版本，遇见兼容性错误的话记得上报

2. 新建 standard 目录于本仓库目录下，放入两个文件：

    - name_id.json

    应为同学的学号与姓名对照表，格式如下（以%%扩起的内容需根据词义替换）：
    ```json
        {
            "%学号字符串%": ["%姓名字符串%", ]
        }
    ```

    - referance.json

    应为综测分数参考表，格式如下：
    ```json
    {
        "%一级指标%":{
            "%二级指标%":{
                "三级指标":"%三级指标描述%",
                "基础分": %基础分%,
                "满分": %满分%,
                "默认加分": %默认加分%,
                "共用": "%共用基础分和满分的二级指标名称%"
            }
        }
    }
    ```

    如果没有共用基础分和满分的二级指标，则共用字段为 `null`

3. 新建 result 目录于本仓库目录下，用于存放输出结果文件

4. 运行 main_UniTestApp.py

5. 请注意，学生们填写的综测证明需依照金羿给出的腾讯文档格式保存问 xlsx 和 附件压缩包 形式。该内容需向作者咨询。
